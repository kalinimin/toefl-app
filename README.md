# TOEFL-тренажёр

Личное приложение для подготовки к TOEFL iBT (формат 2026). Expo SDK 58, React Native, TypeScript.

## Веб-версия

```sh
npm ci
npm run web
```

В «Настройках» укажите публичный репозиторий GitHub с `index.json`, затем на главной нажмите «Обновить задания». Если вы используете другой сервер контента, он должен разрешать браузеру читать JSON через CORS.

Задания и настройки сохраняются в браузере. Ключ Azure Speech хранится в памяти вкладки до перезагрузки. Каталог и предпросмотр заданий доступны, а реализация упражнений остаётся будущей задачей.

Команда `npm run build:web` создаёт сайт в `dist/`. При размещении настройте возврат `index.html` для маршрутов приложения, чтобы прямые ссылки на разделы и задания открывались после перезагрузки.

## Структура

```
src/
  app/                 экраны (Expo Router)
    _layout.tsx        навигация + база SQLite
    index.tsx          главный экран: секции, обновление заданий
    settings.tsx       адрес контента, регион и ключ Azure
    section/[section]  список заданий секции
    task/[id]          экран задания (сюда подключаются модули)
  components/ui.tsx    общие элементы интерфейса, светлая/тёмная тема
  lib/
    types.ts           типы заданий
    db.ts              таблицы tasks, results, kv
    content.ts         загрузка заданий с GitHub по index.json
    settings.ts        настройки; ключ Azure — в защищённом хранилище
eas.json               профили сборки APK
```

## Первый запуск (development build)

Нужны Node.js LTS и аккаунт на expo.dev.

1. Установить зависимости:

   ```
   npm install
   ```

2. Войти в Expo и собрать тестовую сборку в облаке (первый раз EAS спросит, создать ли проект и ключ подписи Android — отвечайте «да»):

   ```
   npx eas-cli@latest login
   npx eas-cli@latest build --profile development --platform android
   ```

   Когда сборка закончится, откройте ссылку из терминала на телефоне, скачайте APK и установите (разрешите установку из неизвестных источников).

3. Запустить сервер разработки на компьютере:

   ```
   npx expo start
   ```

   Телефон и компьютер должны быть в одной сети Wi-Fi. Откройте на телефоне установленное приложение и выберите сервер или отсканируйте QR-код из терминала камерой.
   Если телефон не видит компьютер, запустите `npx expo start --tunnel`.

4. В приложении: «Настройки» → ссылка на репозиторий `toefl-content` → «Сохранить» → «Обновить задания».

Пересобирать APK (шаг 2) нужно только после добавления библиотек с нативным кодом. Изменения в коде появляются на телефоне сразу.
